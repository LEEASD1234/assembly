# 프로시저

## 스택 명령어 및 작동 원리
* PUSH	: ESP를 감소시키고(Decrement), 소스 피연산자를 ESP가 가리키는 스택 위치로 복사한다.
* POP : ESP가 가리키는 스택 내용을 목적지로 복사한 후, ESP를 증가시킨다.

## 스택의 주요 활용 목적
* 런타임 스택은 다음 네 가지 주요 목적으로 사용된다.
** 지역 변수 저장(Local Variable Storage) 
** 레지스터 임시 저장(Register Saving) 
** 인자 전달(Argument Passing) 
** 복귀 주소 저장(Return Address Storage): 서브루틴 호출 중 복귀 주소를 저장한다.

## 특수 스택 명령어
* PUSHAD / POPAD : 32비트 범용 레지스터 전체 (EAX, ECX, EDX, EBX, ESP, EBP, ESI, EDI 순서)를 스택에 저장하거나(PUSHAD), 역순으로 복구한다.(POPAD).
* PUSHFD / POPFD : 32비트 EFLAGS 레지스터의 내용을 스택에 저장하거나 복구한다.

## 프로시저 정의 및 사용
* 어셈블리에서 프로시저는 PROC와 ENDP 지시어로 정의되며, 고수준 언어의 함수나 메서드와 유사
* 복귀 (RET) : RET 명령어는 CPU가 프로시저가 호출되었던 위치(스택에서 복귀 주소를 팝)로 되돌아가도록한다.


## 매개변수 전달 및 레지스터 보존
* 인자 전달 : 어셈블리 언어에서는 일반적으로 범용 레지스터를 통해 인자를 전달한다.
* 레지스터 보존 : 프로시저 내에서 수정된 레지스터는 호출자에게 영향을 주지 않도록 PUSH와 POP 명령어를 사용해 저장하고 복구.
* USES 연산자 : PROC 지시어에서 USES 키워드를 사용하여 레지스터 이름을 지정하면, 어셈블러가 해당 레지스터들에 대해 프로시저 시작 부분에 PUSH를, 종료 부분(RET 직전)에 POP 명령어를 자동으로 생성. (단, 반환 값으로 사용되는 레지스터(일반적으로 EAX)는 USES에 포함하지 않는다).
