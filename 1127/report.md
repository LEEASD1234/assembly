## 고급 배열

# 1. 문자열 기본 명령어
32비트 모드에서 문자열 기본 명령어는 메모리 주소를 지정하기 위해 ESI (소스 인덱스) 및 EDI (대상 인덱스) 레지스터를 암시적으로 사용하며, ECX 레지스터를 카운터로 사용하여 효율적인 반복 작업을 수행합니다
* MOVSB/W/D : 메모리 주소 ESI에서 EDI로 문자열 데이터를 복사합니다
* CMPSB/W/D : ESI가 가리키는 메모리와 EDI가 가리키는 메모리의 내용을 비교합니다
* SCASB/W/D : 누산기 (AL/AX/EAX)의 내용을 EDI가 가리키는 메모리 내용과 비교하여 특정 값을 검색합니다
* STOSB/W/D : 누산기 (AL/AX/EAX)의 내용을 EDI가 가리키는 메모리 위치에 저장합니다
* LODSB/W/D : ESI가 가리키는 메모리의 내용을 누산기 (AL/AX/EAX)로 로드합니다

# 2. 반복 접두어 및 방향 플래그
반복 접두어
* 하나의 문자열 기본 명령어는 단 하나의 값만 처리하므로, 배열 전체를 처리하려면 반복 접두어를 사용해야 합니다. 반복 시 ECX가 카운터로 사용됩니다
* REP : ECX가 0보다 클 때까지 반복합니다(일반적인 복사/저장 작업에 사용)
* REPE (REPZ): Zero 플래그가 설정되어 있고 ECX가 0보다 클 때까지 반복합니다. (비교 작업 시 두 값이 '같을' 때까지 반복)
* REPNE (REPNZ): Zero 플래그가 클리어되어 있고 ECX가 0보다 클 때까지 반복합니다. (검색 작업 시 두 값이 '같지 않을' 때까지 반복)
방향 플래그
* 문자열 기본 명령어는 **방향 플래그(DF)**의 상태에 따라 ESI와 EDI 레지스터를 증가시키거나 감소시킵니다
* CLD (Clear Direction Flag): DF를 클리어하여 정방향 (Low-high), 즉 ESI와 EDI를 증가시킵니다. (일반적인 순차 처리)
* STD (Set Direction Flag): DF를 설정하여 역방향 (High-low), 즉 ESI와 EDI를 감소시킵니다.

# 3. Irvine32 라이브러리의 문자열 프로시저
문서에서는 널(Null)로 끝나는 문자열을 조작하는 Irvine32 라이브러리의 여러 프로시저를 소개합니다
* Str_length: 문자열의 오프셋을 인자로 받아 문자열의 길이를 EAX 레지스터에 반환합니다
* Str_copy: 널로 끝나는 문자열을 소스 위치에서 대상 위치로 복사합니다. 대상 공간이 충분히 커야 합니다
* Str_trim: 널로 끝나는 문자열에서 선택된 후행 문자를 모두 제거합니다
* Str_ucase: 문자열의 모든 문자를 대문자로 변환합니다

# 4. 고급 배열 및 검색/정렬
2차원 배열
* 2차원 배열에 접근할 때는 베이스-인덱스 피연산자를 사용하여 행 오프셋(베이스 레지스터)과 열 오프셋(인덱스 레지스터)을 결합하여 유효 주소를 계산합니다
정렬 및 검색
* 버블 정렬 (Bubble Sort): 배열 값을 쌍으로 비교하여 역순일 경우 교환하는 방식으로, n-1번의 패스 후에는 배열이 정렬됨을 보장합니다
* 이진 검색 (Binary Search): 정렬된 배열에서 특정 값을 찾는 효율적인 방법입니다.
* 배열의 중간점을 계산하고, 검색 값(searchVal)을 중간점의 값과 비교합니다.
* 비교 결과에 따라 검색 범위를 절반으로 줄여 first 또는 last 인덱스를 재설정하며 반복합니다.
* 일치하는 값을 찾으면 해당 배열 위치를 반환하고, 범위를 초과하면 검색에 실패했음을 알립니다
