# 데이터 전송, 주소 지정 및 산술

## Operand 타입
* re8 : 8비트 범용 레지스터 (AH,AL,BH,BL,CH,CL,DH,DL)
* reg16 : 16비트 범용 레지스터 (AX,BX,CX,DX,SI,DI,SP,BP)
* reg32 : 32비트 범용 레지스터 (EAX,EBX,ECX,EDX,ESI,EDI,ESP,EBP)
* reg : 공용(8,16,32비트) 범용 레지스터
* sreg : 16비트 segment 레지스터 (CS,DS,SS,ES,FS,GS)
* imm : 8,16,32비트의 직접적인 값
* imm8 : 8비트의 직접적인 byte 값
* imm16 : 16비트의 직접적인 byte 값
* imm32 : 32비트의 직접적인 byte 값
* reg/mem8 : 8비트 Operand, 8비트의 전반적인 레지스터 혹은 메모리 byte
* reg/mem16 : 16비트 Operand, 16비트의 전반적인 레지스터 혹은 메모리 byte
* reg/mem32 : 32비트 Operand, 32비트의 전반적인 레지스터 혹은 메모리 byte
* mem : 8,16,32비트 메모리 Operand

## DATA 전송 명령어
* MOV : 소스 피연산자를 목적지 피연산자로 복사합니다. 두 피연산자는 크기가 같아야함.
* XCHG : 두 피연산자의 값을 서로 교환
* MOVSX : 부호있는 작은 크기의 피연산자를 더 큰 크기의 피연산자로 복사할때, 부호 비트를 확장하여 값의 부호를 보존.
* MOVZX : 부호없는 작은 크기의 피연산자를 더 큰 크기의 피연산자로 복사할때, 사위비트를 0으로 채움.

## 주소 지정 방식
* 즉시 주소 지정 : 명령어 자체에대한 데이터값 포함.
* 레지스터 주소 지정 : 피연산자가 CPU내 레지스터.
* 직접 주소 지정 : 명령어에 메모리 변수의 유한 주소가 포함
* 레지스터 간접 주소 지정 : 데이터가 저장된 메모리의 주소를 담고있음.
* 인덱스 주소 지정 : 베이스 레지스터와 인덱스 레지스터를 사용하여 배열 요소에 접근할때 사용.
* 베이스-인덱스 주소 지정 : 베이스 레지스터와 인덱스 레지스터의 합을 주소로 사용.

## 산술 연산 명령어
* ADD/SUB : 두 피연산자를 더하거나/빼기
* INC/DEC : 피연산자의 값을 1 증가/감소
* NEG  : 피연산자의 부호를 반전
* IMUL : 부호있는 정수 곱셈을 수행
* IDIV : 부호있는 정수 나눗셈을 수행

## LOOP
* LOOP : ECX 레지스터를 카운터로 사용하여 루프실행, ECX를 1감소, ECX가 0이아니면 지정된레이블로 점프.

## 변수정의
* LENGTHOF 연산자 : 배열요소의 개수를 반환
* SIZEOF 연산자 : 배열전체가 차지하는 바이트 크기를 반환.
* TYPE 연산자 : 배열요소 하나의 바이트를 반환
